HR Analytics Dashboard
Employee Attrition & Workforce Insights | Power BI
Project Overview
An interactive HR Analytics Dashboard developed using Microsoft Power BI to analyze employee attrition, workforce demographics, job satisfaction, and employee experience. The dashboard transforms HR data into meaningful visualizations, helping organizations understand workforce trends and support data-driven HR decisions.
Project Objectives
- Analyze employee attrition and retention trends.
- Understand workforce demographics and departmental distribution.
- Evaluate employee satisfaction and work-life balance.
- Identify key workforce patterns through interactive visualizations.
- Support effective HR planning and decision-making.
Dashboard Pages
1. HR Analytics Dashboard – Employee Attrition & Workforce Insights
This page provides an overview of key HR performance indicators, including:
- Total Employees
- Employee Attrition Status
- Attrition Rate
- Average Years at Company
- Job Satisfaction
- Employees by Gender
- Department-wise Attrition
- Education Field Distribution
2. Employee Demographics – Workforce Profile & Diversity Insights
This page focuses on workforce composition and employee characteristics, including:
- Average Employee Age
- Average Distance from Home
- Average Work-Life Balance
- Department and Gender Distribution
- Business Travel Analysis
- Education Field Distribution
- Environment Satisfaction
- Marital Status Distribution
Key Features
- Interactive two-page Power BI dashboard
- Dynamic KPI cards and visualizations
- Department-wise employee filtering
- Employee attrition and retention analysis
- Workforce demographic insights
- Job satisfaction and work-life balance analysis
- Interactive charts, tables, and slicers
Tools & Technologies
- Microsoft Power BI
- Power BI Data Modeling
- Data Visualization
- HR Data Analysis
Dataset Information
The project uses an HR Analytics dataset containing 1,470 employee records and 35 attributes. Interactive filters allow users to explore specific departments and employee groups.
How to View the Dashboard
1. Download the Power BI (.pbix) file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Navigate between the two dashboard pages.
4. Use interactive filters to explore workforce insights.
Conclusion
This project demonstrates how Business Intelligence can be applied to Human Resource Management. By analyzing employee attrition, demographics, satisfaction, and workforce distribution, the dashboard provides useful insights to support employee retention strategies and organizational planning.
